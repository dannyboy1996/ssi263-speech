# Robovox research: patent, 1998 tour rig, and what the VST emulates

Target: Kraftwerk's Robovox as used on the 1998 tour — an SC-02-based
singing voice played from a MIDI sequencer/keyboard. The chip emulation is
this repo's existing SSI-263 model (`src/csrc/ssi263.c`, the SC-02 under
Votrax's name); this document covers everything around it.

Your recollection was right: **phonemes on channel N, pitch on channel
N+1 via the Inflection register.** That is the patent's first embodiment,
verbatim.

## 1. The patent: EP0396141A2

- "System for and method of synthesizing singing in real time", inventors
  Florian Schneider, Gert Joachim Ott, Gert Jalass. Priority 1989-05-04
  (DE), filed 1990-05-03, published 1990-11-07. Status: **withdrawn**
  (never granted; no rights to clear, but also no granted-claims detail).
- Incorporates by reference: the Votrax SC-02 data sheet and MIDI 1.0.
- Hardware (Fig. 1): `CPU 10 (may be a 6502)` + `ROM 12 (may be a 6116)` +
  address decoding 13 on bus 14, clock generator 18, `MIDI interface 15
  (mainly an ACIA 6850)`, buffer register 16 (`two 75LS245`), one or more
  `SC-02 speech processor chips 17`, audio-out buffer 19, audio-in 20 at
  SC-02 pins 3 and 5 (external excitation replaces the internal tone
  generator, switch 22), mode selection 21.
- Note the patent's `6116` is a 2Kx8 **SRAM**, not a ROM — almost
  certainly a part-number slip for a 2 KB EPROM (2716) or a
  ROM-plus-SRAM mixup. The VST bus models a 2 KB ROM socket plus 2 KB RAM.
- SC-02 "provides 8 registers, of which 5 are used in the singing
  process: **Phoneme, Inflection, Articulation, Amplitude and Filter
  Frequency**".

### 1.1 Embodiment 1 (the N / N+1 one — default VST mode)

> "MIDI Note On events received on a MIDI channel N … turn on a specific
> phoneme by writing the number of the phoneme into the Phoneme register
> … The phoneme number is generated by a translation table which
> translates the Note Number into a phoneme number. The Velocity … is used
> to affect the Amplitude register … Note Off … turn off the phoneme by
> writing the code for the phoneme 'Pause' … Note On events received on
> channel N + 1 … select the appropriate singing frequency … translated
> into values for the Inflection register … based on a tuning frequency
> of 440 Hz for a′. Pitch Wheel … Filter Frequency … Modulation Wheel …
> Articulation register."

- Phoneme channel N: Note On → phoneme table lookup → Phoneme reg;
  velocity → Amplitude reg; Note Off → Pause (SC-02 code **0**, cf.
  `third_party/casso/CassoEmuCore/Devices/Ssi263.cpp:24` — `00 PA`).
- Pitch channel N+1: Note On → Inflection reg (12-bit pitch, A4 = 440 Hz);
  velocity → Amplitude; Note Off → Amplitude 0.
- Pitch wheel → Filter Frequency (vocal-tract length); mod wheel →
  Articulation (filter-interpolation speed); velocity → loudness.
- Pairs are N/N+1; the four-chip build uses speech on **1, 3, 5, 7** and
  pitch on **2, 4, 6, 8** (patent: "keys 36-93 control speech sounds on
  channels 1, 3, 5 and 7 whereas the pitch control is controlled on
  channels 2, 4, 6 and 8"). Notes 36–93 = 58 keys for the chip's 54
  phonemes (Fig. 2 groups: dark→bright vowels, voiced, voiceless,
  plosives).

### 1.2 Embodiment 2 (expander style — VST option)

Channel N Note On → Inflection (pitch); velocity → Amplitude; Note Off →
Amplitude 0; **Program Change → phoneme** via program-number table.
Same wheels. Behaves like a normal MIDI expander with voice-like timbres.

### 1.3 Five modes (front-panel rotary on the tour hardware)

1. **SEQ** (sequencer): keyboard or up to N sounds from any sequencer.
2. **POLY**: N identical voices, different pitches, Program-Change select.
3. **MONO**: N different sounds like organ stops, one key at a time.
4. **FILTER**: filters stationary, external source through; Program Change
   sets filter parameters (the SC-02 as a MIDI multiband filter).
5. **SPLIT**: SEQ + N-voice polyphonic combined.
- Plus: envelope (attack/decay, all sounds but plosives) via "specific
  MIDI control change sequences" (numbers not disclosed in the patent —
  see §5); phoneme-editor/compiler score format with `:L:` loudness 0–9
  and `T` pitch over a 24-ppq MIDI-clock frame grid; vibrato/portamento
  obtainable; external carrier (waveforms, noise for whisper, chords)
  through the filter bank for choir/organ/vocoder timbres.

## 2. The 1998 tour rig vs the patent

- 1998 equipment list (kraftwerkfaq.com/equipment.html) names Robovox
  among the tour rig (Nord Lead 2, Kawai K5000s, Doepfer MAQ 16/3 /
  Regelwerk / Schaltwerk sequencers, Akai samplers, Tascam DA-88, …).
- Operation was sequencer-driven: custom software on an **Atari 1040ST**
  (matrixsynth/düsseldorfhbf account of an ex-Kraftwerk unit: "one of four
  MIDI Robovoxes … originally used in conjunction with custom software
  written for the Atari 1040ST"); by 1998 the Atari role is plausibly
  absorbed by the Doepfer hardware sequencers, but the two-track method
  (one track phonemes, one track pitch) is the same.
- Surviving hardware (Julien's sale of Schneider's rack: two "Robovox
  Sculpture" MIDI racks + seven Votrax VS-6 + Telefunken unit + phoneme
  keyboard) shows exactly the patent's UI grown up: rotary **SEQ / POLY /
  MONO / SPLIT / FILTER**, MIDI 2 selector, four INT/EXT toggles
  (internal vs external excitation per voice), on/off + reset. The VS-6
  boxes in the same rack are the earlier fixed-pitch generation (cf. the
  Hybrid Machine account: early Robovox sang at fixed frequency, pitch
  added afterwards with an Eventide H-3000 — "the only available
  harmonizer which worked properly with artificial speech").
- The contemporary Polaxis recreation (polaxis.be/robovox, built from the
  same patent around a real SC-02) confirms the live-performance control
  set the VST copies: notes → phonemes, velocity → loudness, **CC1 =
  master clock (coarse pitch), CC2 = inflection (fine pitch), mod wheel =
  filter, CC3 = control/transition rate, CC64 = internal/external
  carrier**, PEC VST sequencer plug-in in the style of the Atari software.

### Patent → tour deltas (what the VST does about each)

| # | Patent (1990) | 1998 tour reality | VST treatment |
|---|---|---|---|
| 1 | Live keyboard, two channels | Sequencer two-track (phoneme track + pitch track), Atari/Doepfer | Identical handling; sequencer input is just recorded Note On/Off |
| 2 | Fixed chip clock implied | Variable master clock = coarse pitch (lower MIDI interface → oscillator in the prototype; CC1 on Polaxis) | `Master Clock` param, ±octaves around nominal XCK |
| 3 | Single or quad SC-02 | Rack of voices (quad mappings 1/3/5/7 + 2/4/6/8) | 1-voice SEQ default; 4-voice QUAD option |
| 4 | Internal excitation | INT/EXT per-voice switches; vocoder/harmonizer downstream | `Carrier` audio input + INT/EXT mix (chip TP1/TP2 path is future work — see §5) |
| 5 | Fig. 2 note→phoneme table | Same table, exact print unrecovered | Editable default table, notes 36–93 (placeholder order, §5) |
| 6 | Envelope CC sequences | Unknown numbers | Exposed as Attack/Decay params driving Amplitude slew; CC learn |

## 3. SC-02 register map (what the translator writes)

From the SC-02 data sheet via this repo's engine (`src/csrc/ssi263.c`,
`src/csrc/ssi263.h`):

| Reg | Addr | Content | Engine reference |
|---|---|---|---|
| R0 | 0 | bits 0–5 phoneme (0–63, 0 = PA pause); bits 6–7 DUR/mode | `ssi263.c:295`, `:319-324` (duration = frame·(4−DUR); mode 1 = 1 frame) |
| R1 | 1 | Inflection low 8 bits; in pitch-glide mode high 5 bits = target, **low 3 bits = glide rate** | `ssi263.c:327-342` |
| R2 | 2 | high nibble = RATE (speech rate); low nibble = inflection top bits (bit 3 = I11, bits 0–2 = I2–0) | `ssi263.c:329-330`, `:319` |
| R3 | 3 | high 3 bits = ART (articulation); low nibble = amplitude; **bit 7 = CTL/power** (set at power-up; 1→0 latches mode) | `ssi263.c:193`, `:461-467`, `:564` |
| R4 | 4–7 | FF: filter clock fc = XCK / (2·(256−FF)) | `ssi263.c:546` |
| Pitch | — | F0 = XCK / (8·(4096−I)), I = 12-bit inflection | `ssi263.c:613` |

So to the "pitch glide time" question: **yes, the chip does it** — R1's
low 3 bits set the glide slope (`glide_field_mult`, `ssi263.c:581-582`),
scaled by rate. The VST exposes it as `Glide`. Articulation (R3) sets
formant-transition speed in codes/frame (`art_codes_per_frame`,
`ssi263.c:564`); Filter Frequency (R4) scales every resonance with fc.

Tuning math (XCK = 1 MHz default, `ssi263_defaults.h:8`):
I(f) = 4096 − XCK/(8·f); A4 440 Hz → I = 3812 (R1 = 220, R2-lo = 0xC
with rate in the high nibble). The translator computes this per note, so
`Master Clock` (XCK) retunes everything coherently, exactly like the
hardware's variable oscillator.

## 4. Emulator decisions

- **6502**: floooh `chips` `m6502.h` (MIT, header-only, cycle-accurate,
  pin-callback style — no framework to port). See `third_party/README.md`
  for why MAME's 6502 was rejected (device-framework coupling, GPL
  project umbrella).
- **6850 ACIA**: clean-room `emu/mc6850.h` (~200 lines). MIDI needs only:
  master-reset + /16 divide select, 8N1, RDRF/TDRE/OVRN status, Rx IRQ
  enable. Byte-level model with framing check; 500 kHz Tx/Rx clocks
  implied. Behavior pinned by `tests/test_6850_midi.c`.
- **Bus** (`emu/robovox_bus.h`): 6502 socket, 2 KB RAM + 2 KB ROM socket
  (the 6116 footnote, §1), 6850, 2×74LS245 latch to the SC-02 register
  addresses (`ssi263.h:104`: addrs 0–3 → R0–R3, 4–7 → R4), mode switch,
  XCK generator. IRQ: 6850 Rx → 6502 IRQ, as in the patent.
- **Firmware**: the original ROM/Atari software is lost, so
  `emu/robovox_firmware.h` is a new implementation of the patent text
  (embodiment 1 default, embodiment 2 optional). Phase 2 moves it into a
  6502-resident ROM image running on the emulated core; the bus, vectors
  and translator API are already shaped for that.

## 5. Open questions (tour-hardware unknowns)

1. Exact Fig. 2 note→phoneme order (which of notes 36–93 map to the 54
   codes, and the 4 spare keys). Current table is an editable placeholder
   following the patent's dark→bright ordering description.
2. Nominal XCK of the tour units (1 MHz assumed; Atari-era units may have
   differed — everything pitch-related scales with it).
3. Envelope CC numbers ("specific MIDI control change sequences" —
   undisclosed; Polaxis CC1/CC2/CC3/CC64 mapping adopted where it fits).
4. TP1/TP2 external-excitation analog path (patent: pins 3+5; repo
   `docs/sources.md` notes EP0396141A2 as the lead). VST models carrier
   select at the input for now, not injection behind the glottal source.
5. Quad-voice tour wiring (which chip sang lead vs choir; MONO organ-stop
   assignments) and the Telefunken unit's f/s/d role.
6. Whether the '98 rig still used the 6502 boards or had moved to
  Atari/Doepfer-direct serial MIDI — sonically equivalent either way;
  the emulation keeps the patented CPU path.

## 7. Polaxis Robovox (living patent-derived reference)

Polaxis (Jean-Luc Deladrière, polaxis.be) ships a modern Robovox: a real
SC-02 on a MikroBUS board for the Emy/Terminal/Kraftor hosts, firmware in
Serial-MIDI and USB-MIDI builds, a PEC VST sequencer plug-in "almost like
the original Atari software used by Kraftwerk", and an Ableton rack that
names piano-roll notes after phonemes. The Robovox user manual (Google
Doc linked from polaxis.be/robovox, hardware v2019, firmware through
0.07 / 11-08-2021) gives the complete control map, which the VST adopts
where it does not conflict with the patent:

- MIDI Note On/Off → SC-02 phonemes; Velocity (7-bit) → loudness.
- **Pitch Bend (14-bit) → coarse pitch by clocking the chip.** This is
  the tour rig's "lower MIDI interface → oscillator clock" in modern
  form (cf. §2): pitch is split coarse (XCK) / fine (inflection).
- **CC2 → Inflection/pitch register (fine)** (added firmware 0.06,
  24-07-2020).
- **Mod wheel → vocal-tract filter** (7-bit); **CC3 → control rate**
  (formant-transition movement, 7-bit; added 0.07 — Andrew Shaw runs it
  near max for the choppy "Tribal/Nummweltverschmutzung" cover).
- **CC64 (sustain) → internal/external carrier** (off < 64, on ≥ 64),
  paralleled by the board's INT/EXT switch (middle = external, lower =
  internal). Carrier ≈ 2 V into the jack/op-amp; too weak = muffled +
  noise, too hot = cracking. Doubles as an effect send: any signal
  through the phoneme filters.
- CV/P1–P4 mirror: master clock, inflection, filter frequency, rate;
  P5 = phoneme randomization (later disabled); Gate triggers phonemes in
  CV mode; rotary selects MIDI channel; Busy jack carries MIDI clock.
- PEC plug-in workflow = the Kraftwerk workflow per Shaw: enter SC-02
  phonemes as text, `/` markers split segments to equal note lengths
  (1/4, 1/8…), render/manipulate (stutter, randomize), then perform pitch
  live — phonemes first, timing second, tuning last, all streamed from
  the DAW. The VST's editor copies this layout (phoneme score field +
  segment grid + live pitch lanes).

Patent-vs-Polaxis control differences (both kept selectable in the VST,
`CtlMap` param): patent pitch-bend → Filter Frequency and mod → 
Articulation; Polaxis pitch-bend → master clock, CC2 → inflection, mod →
filter, CC3 → rate. One Reaper-automation screenshot captions the clock
lane "CC1", contradicting the manual's 14-bit Pitch entry — treated as a
caption slip; the manual rules. Envelope CC numbers remain unknown in
both (patent "specific sequences"; Polaxis exposes no attack/decay CC),
so Attack/Decay stay VST-side params on the Amplitude slew.

### 8.3 The seven VS-6 boxes are NOT SC-02 (service-manual evidence)

The VS-6 is Richard T. Gagnon's earlier discrete generation
(US 3,908,085 class: 64 phonemes/16 parameters, active filters), and the
full VS-6.0 service manual (Vocal Interface Division P/N 936–943,
95 pp., via bitsavers) pins down what's inside those seven boxes:

- **63 phonemes × 4 inflections** (IN1–IN4 = 2 bits of an 8-bit command
  word; 6 bits phoneme + 2 bits inflection = 252 inputs). Fixed
  inflection levels — no inflection *register*; pitch is stepped, which
  is exactly the limitation Schneider's "larynx" mod worked around.
- **Seven plug-in PCBs**: voice generator on **four epoxy-encapsulated,
  color-coded boards** (potted — no component-level servicing), parallel
  interface on two repairable boards, plus serial-interface (RS-232C,
  110–1200 baud, XTAL baud clock with JP3/JP4 rate jumpers and
  parity/stop-bit selects), keyboard-interface, and ROM-vocabulary boards.
  Servicing = rear panel off (four captive thumb screws), keyed boards
  out of the front motherboard.
- Labeled **phoneme keyboard** generating the 8-bit command words
  directly (the ancestor of the Sculpture rig's phoneme track); the rack's
  keyboard is this family (donor plaque on the hand-built controller:
  Votrax/Federal Screw Works model **6-931**, s/n 9786 8M28).

So the rack spans **two generations**: Gagnon-archive "Singing Computer"
(68000 CPU → VS-6s, external-audio "larynx" mod for polyphonic
chords/noise/whisper) underneath, and the patented 6502 + 6850 → SC-02
Sculpture Robovoxes on top. The VST models the Sculpture side; a VS-6
voice (stepped inflections, ASCII command words, no chip registers)
would be a separate instrument, noted on the roadmap. A future "Rack"
mode could mix 2× SC-02 + VS-6-style voices the way the case does.

### 8.4 The hand-built controllers (separate Julien's lot, Schneider's own work)

Two 16×10×9 in. metal boxes on a stand, used with the rack at Kling Klang:

- Box 1: 40-key phoneme keyboard hardwired to **2× Doepfer CTM64 MIDI
  boards (one dated 2007)**, four pots, on/off + lamp, VU meter, toggle +
  momentary button; rear: single MIDI jack, IEC, fuse.
- Box 2: 2× CTM64 wired to matrix switches, two pot banks with hand
  labels, toggles + yellow momentaries, on/off + lamp.

The 2007 CTM64 dates the live phoneme-keyboard rig to the late Kling Klang
years — the Robovox stayed on stage long after the Atari era.

### 8.5 Paper trail and technician accounts

- **Gagnon archive** (Erik Richard Gagnon → Julien's): Schneider's
  handwritten margin notes list Votrax deployments ("1975 Radio
  Activity", "1980 Computer World", "Uranium", "Numbers", "It's More Fun
  to Compute"); Gagnon writes to *Schneider* asking how to compute
  formant wave functions within 8-bit arithmetic; "Votrax CPU (Direct)
  Phonetic KBD" diagram matches the rack keyboard; a phonetic
  transcription of Kurtis Blow's "The Boogie Blues" shows the working
  method (deconstruct records into Votrax phonemes).
- **The Mix (1991) sleeve**: Ott under hardware, Jalass under software
  (Aktivitaet) — the credited builders, matching the patent's inventors
  minus Schneider.
- **Stephen Morris (New Order)** tribute: the Robovox "looked like it
  walked off the set of Dr Who"; Orchestron choir on "Uranium"; his own
  failed Blue Monday attempt at the robot growl with a plug-in computer
  board.
- **KVR 2012 practitioner consensus** (Gamma-UT et al.): Robovox debut =
  The Mix (1991), Bartos's Esperanto LP = same technique; Man Machine /
  Ohm Sweet Ohm / Radioactivity voices = vocoder; "Uranium" = Votrax
  candidate; kraftwerkfaq's "military phoneme synth on Radioland";
  freepatentsonline EP0396141 PDF; Votrax Votalker C64 cartridge.
- **Doepfer MAQ 16/3** (Music Technology, Jul 93 review): Kraftwerk-fed
