# SSInger default note -> phoneme map (phoneme MIDI channel N)
#
# REFERENCE ONLY. This file documents the key layout compiled into the
# VST (ssinger_default_table in emu/ssinger_firmware.h). The plugin does
# not read it -- there is nothing to install or keep next to the .vst3.
# A custom layout becomes a UI feature (Phase-2 PEC-style editor), not
# a sidecar file.
#
# Note names use C4 = middle C = MIDI 60 (scientific pitch notation /
# Yamaha / MMA convention: octave = (midi_number // 12) - 1, e.g.
# 60 -> C4, 69 -> A4). Some DAWs label differently (Ableton/Cubase call
# 60 C3, FL Studio calls it C5) -- shift every octave digit here by -1
# or +1 to match those; the MIDI numbers are what the VST receives.
# (The Polaxis manual writes note 36 as "C1", i.e. the C3=60 convention;
# that is C2 here. Same key, different label.)
#
# Range covers all 63 sounding codes, notes 36-98, in chip-code order
# (dark->bright vowels, voiced stops, unvoiced stops, holds, fricatives,
# nasals, German vowels). Code 0 (PA, silence) has no key -- Note Off
# writes it. Notes outside 36-98 are unmapped and ignored on the phoneme
# channel. The patent text says "54 phonemes" and Fig. 2 spans keys
# 36-93, but the chip carries 64 codes (0x00 PA .. 0x3F LB in
# src/data/rom_bits.csv); the top octave past key 93 is the extension
# that makes M N NG :A :OH :U :UH E2 LB playable.
#
# NOTE: the Polaxis hardware anchors note 36 = U (code 0x16), i.e. its
# table is arranged phonetically, not in chip order. Until the patent's
# Fig. 2 keyboard print is transcribed, this chip-order table is the
# default. Generated from the firmware -- do not hand-edit the lines
# below without updating the code (and note_map.txt stays
# documentation, not input).
#
# Phoneme mnemonics are the SC-02 die-ROM order (see
# third_party/casso/CassoEmuCore/Devices/Ssi263.cpp): PA E E1 Y YI AY
